# Interface previews

These PNG files are used by the repository's [main README](../../README.md).

- `receiver-panel.png`: the supplied DAC-style receiver interface, with the
  station name and channel number replaced by neutral dashes. No channel is
  selected in this presentation. The panel, controls, clock, and dial are
  otherwise unchanged.
- `live-tv-window.png`: the supplied viewing-window interface with an empty
  video area, retained without pixel changes.

Both images are 2048 pixels wide and are bundled locally so the README does not
rely on an external image host. They illustrate the interface, not a measured
playback or hardware-compatibility result.
