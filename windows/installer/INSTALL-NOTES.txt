Open Volar S 0.9.5

Version 0.9.5 adds standard BDA discovery registration for x64 and x86 clients,
numeric channel ordering, and a Windows installer build from Linux. Linux also
receives standard DVB support, automatic device permissions and larger interface
fonts. Windows font sizes are unchanged.

The Linux-built Windows installer includes the GNU runtime DLLs. It uses the
existing WinUSB binding and does not install a signed kernel driver. Windows
hardware playback still needs validation on Windows.

Open Volar S 0.8.0-alpha.43

The receiver panel title now uses plain cream text matching the stream panel.

Open Volar S 0.8.0-alpha.42

Adds 16:10 and 5:4 to Settings > Video > Aspect ratio. Both retain the existing styling, save across restarts and apply through the shared presentation geometry. Auto detects the reported stream ratio, including changes during playback. Includes the alpha.41 backend-switching and DirectX playback improvements.

The stream window's maximize button restores its previous normal size and position when clicked again. Resizing batches stream controls and draws the same chassis artwork without full-window CPU resampling or relaying out Settings and the receiver panel.

Open Volar S 0.8.0-alpha.41

This update repairs video-window lifetime when changing playback backends and EVR repaint handling. Microsoft decoding with DirectX 11/12 picture effects uses paced Vulkan presentation when available, keeping effect processing off the audio delivery thread. Windows EVR remains available when Vulkan graphics is unavailable.

Vulkan decoding retains Vulkan shaders and its direct GPU frame-sharing path. The costly Vulkan-to-DirectX frame-transfer experiment is not included. The five device-loss retry policy is unchanged.

The installer updates the existing per-user Live TV shortcut. Source and installer use the same version. See docs/ALPHA41-VALIDATION.md for measured results and verification limits.

Open Volar S / Live TV! 0.8.0-alpha.40

Vulkan remains the default decoder. Settings > Video > Decoder also offers Microsoft processing when its required Windows components are available. Shader acceleration is a separate selector below Decoder. Automatic prefers Vulkan, DirectX 12, then DirectX 11. Microsoft decoding can use any supported shader option. The Vulkan decoder requires its shared Vulkan renderer and offers Automatic or Vulkan. Off (CPU) disables custom picture effects, retaining saved picture preferences for the next GPU selection. CPU ICC correction remains available.

A genuine graphics-device loss releases the failed graph and permits up to five fresh attempts with the same decoder. Unrelated errors stop playback. There is no automatic Microsoft decoder fallback. No driver or firmware modifications are included.

Color profile and Choose ICC share the top row of Video, with extra space before the remaining options. AverTV signal has moved to Video. Its saved confirmation clears after five seconds. Appearance is now Themes. Settings use the common Orbit fields and four interface languages. All tab backgrounds extend to the panel inset; status controls, including Channels, share the same dark fill.

Caption presentation follows video timestamps, holds during pause and follows buffered frame steps. DirectX 12, DirectX 11 and CPU playback share EVR's playback clock, bounded by video delivered to the renderer so captions cannot race ahead during processing stalls. Latin text is approximately 10% larger and remains wrapped inside the picture. Broadcast character casing and cue durations are preserved.

Install and run Live TV as a normal user. The default destination is LocalAppData\Programs\A865R. An old machine-wide copy is not removed automatically. The optional AverTV adapter update appears only when registered adapter files need repair or replacement. Unchanged files do not trigger an elevation request. A protected adapter update or restarting the vendor's service can require administrator approval; skipping that optional update does not prevent using Live TV. The final page offers Run Live TV.

The adapter updater preserves existing registrations, checks staged file hashes and backs up changed DLLs. Close AverTV before updating its adapter. It does not change WinUSB binding or firmware, or create a new BDA registration. AverTV processed modes still require an existing FFmpeg installation. The original broadcast is not altered by playback picture effects.

Recordings retain the original .broadcast.ts; a verified .ts is published after software validation/repair. Processing cannot recover lost broadcast detail. The native diagnostic player replaces bundled mpv. See docs/ALPHA40-VALIDATION.md for measurements, test scope and remaining validation limits.

Standard BDA discovery: Setup now registers the x64 and x86 Open Volar S tuner adapters for the current user. This separate registration step does not change the WinUSB device binding. Restart VLC or other BDA clients after installation.

Wine on Linux: this Linux-built installer installs and starts a private native
helper automatically. Install the Linux package first for driver permissions and
mpv. Use Wine X11/XWayland; the bundled native helper requires glibc 2.43.
No manual authentication token configuration is needed. See docs/WINE.md.
