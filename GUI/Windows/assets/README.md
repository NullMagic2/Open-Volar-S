# Application icon

Approved Open Volar S ruby USB tuner with a white, perspective-mapped unlocked padlock. Drawn in Python; transparent PNG and multi-resolution ICO.

`app.ico` is embedded in Live TV, Debug Desk and the installer. `app-icon.png` is the approved 1024 px artwork. The editable SVG, alternate angle, PNG sizes and drawing source are in `../../../images/`.
